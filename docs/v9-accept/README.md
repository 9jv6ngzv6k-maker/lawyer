# Приёмка v9 — «Досье»

- **Дата:** 25.09.2026 · **Принимал:** `art-director` (режим 2) · **Задание:** `docs/brief-v9.md` · **Коммит:** `c2b3b5c` (сравнение с v8 `db43a93`).
- **Стенд:** Chromium 1194 (Playwright), локальный сервер с gzip (Node, `zlib`), v8 поднят рядом из `git archive db43a93` для сравнения. Ширины 1440, 1024, 768, 390, 360; для Q1 — 1100 и 1200; для отступления 1 — 1366×768, 1536×864, 1920×1080.
- **Особенность стенда:** этот Chromium не декодирует H.264, поэтому `bg-small.mp4` загружается, но стоит на паузе. Проверялись запросы и логика паузы, а не само воспроизведение.

## Вердикт: **ПРИНЯТО**

Все 15 пунктов P1 и все 10 пунктов P2 приняты. Регрессий нет: 0 ошибок в консоли, горизонтальной прокрутки нет, форма работает, reduced-motion и режим без JS в порядке, внешних запросов нет. Четыре отступления фронтенда приняты, по двум есть замечания на v10 (см. ниже).
