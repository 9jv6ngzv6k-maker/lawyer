## Вопросы и ответы

**Одну выплату по ранению уже получил. Может страховая отказать из-за этого?**
Страховая выплата по 52-ФЗ, выплата по Указу № 98 и пособие по 306-ФЗ — по общему правилу самостоятельные основания: получение одной выплаты не лишает права на другую. Проверю по вашим документам. [источник: index.html #voprosy; оговорка — по legal-review В10]

**Какой срок, чтобы судиться со страховой?**
Трёхмесячный срок КАС здесь не действует: это иск по ГПК. Точный срок по вашему спору назову на разборе. Не откладывайте: чем раньше начнём, тем проще собрать документы. [источник: index.html #voprosy «Какой срок на обжалование отказа?»; #tom1 «Иск по ГПК РФ»; «три года» убрано до проверки В5]

**Можно ли обратиться жене или матери?**
Да. Консультация — по вашему рассказу и документам на руках. Доверенность для консультации не нужна. [источник: index.html #voprosy]

**А если оснований для спора нет?**
Скажу прямо — до оплаты следующего этапа. [источник: index.html #kak; legal-editor: «на разборе, до оплаты» убрано — бесплатна только первичная консультация, К2]
