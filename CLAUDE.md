# Халбаев и партнёры — сайт юриста по спорам военнослужащих

Статический сайт без сборки: `index.html` + `assets/`. Язык интерфейса и контента — русский.
Аудитория: военнослужащие, мобилизованные, ветераны и их родственники; многие заходят с телефона, часто по медленной сети.

## Правила проекта

- **Контент — только из источника.** Все факты (цифры «13 лет / 60 дел / 250 споров», дела, нормы права, контакты) берутся из `index.html` и `assets/js/data.js`. Нельзя выдумывать дела, отзывы, суммы, статистику, награды, фамилии судей, гарантии результата.
- **Контакты:** Telegram `https://t.me/llawyerll`, телефон `+7 950 728-92-46`, почта для заявок `yujiklop74@yandex.ru`. Не менять без запроса владельца.
- **Юридическая корректность:** реклама юруслуг не должна обещать результат (38-ФЗ «О рекламе», ст. 5); форма заявки обязана требовать согласие на обработку персональных данных (152-ФЗ) и ссылаться на политику.
- **Внешние ресурсы:** шрифты локальные (`assets/fonts/`), без Google Fonts и сторонних трекеров (ограничения доступа в РФ + 152-ФЗ). Никаких CDN в продакшене.
- **Доступность:** контраст WCAG AA, фокус видим, `prefers-reduced-motion` отключает анимации, всё работает с клавиатуры.
- **Производительность:** первый экран без тяжёлых скриптов; видео — только при нормальной сети и без reduced-motion (так сделано в `assets/js/background.js`).
- Проверка вёрстки — в Chromium через Playwright на ширине 1440 и 390 px (`executablePath: /opt/pw-browsers/chromium-1194/chrome-linux/chrome`, модуль `$(npm root -g)/playwright`).

## Структура

- `index.html`, `assets/` — основной сайт (дизайн «Досье», выбран владельцем).
- `variants/<slug>/` — альтернативные варианты дизайна; каждый самодостаточен, берёт общие шрифты из `../../assets/fonts/`.
- `variants/index.html` — галерея для сравнения вариантов.
- `tools/split_artifact.py` — импорт новой версии артефакта из Cowork.
